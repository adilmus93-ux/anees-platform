# منصة أَنِيـــــس (المسيرة العلمية للدكتور مصطفى العادل)

منصة أكاديمية وتفاعلية متكاملة لنشر وتوثيق النتاج العلمي، الكتب، المقالات، المؤتمرات، والسيرة الأكاديمية للدكتور **مصطفى العادل** (باحث مغربي في اللسانيات العربية ونظريات تحليل الخطاب والتأويليات الحديثة).

---

## 🌟 مميزات المنصة

1. **واجهة أكاديمية عربية أصيلة وعصرية**:
   - خطوط طباعية تراثية وأكاديمية فاخرة (`Amiri` و `Cairo`).
   - مؤثرات أغلفة ثلاثية الأبعاد (3D Book Covers Effect) للكتب والروايات.
   - دعم كامل للوضع الليلي (Dark Mode) والوضع النهاري (Light Mode).

2. **نظام إدارة محتوى ديناميكي كامل (CMS بدون خادم)**:
   - **التحكم في الأقسام**: إضافة أقسام جديدة، تعديل العناوين والأيقونات ونمط العرض، أو حذف أي قسم.
   - **التحكم في المحتويات**: إضافة مؤلفات، كتب جماعية، مقالات، مؤتمرات، شهادات وخبرات جديدة.
   - **رفع الأغلفة والصور**: إمكانية رفع صورة الغلاف مباشرة من حاسوبك أو إدراج رابط صورة خارجي مع معاينة فورية.
   - **رفع المستندات وملفات الـ PDF**: إمكانية رفع ملفات الأبحاث والكتب لتنزيلها أو ربطها بروابط المجلات ودور النشر.

3. **حفظ البيانات والنسخ الاحتياطي**:
   - حفظ تلقائي فوري لكافة التعديلات في الذاكرة المحلية للمتصفح (`localStorage`).
   - **زر تصدير نسخة احتياطية (JSON)**: لتنزيل كامل بيانات المنصة ونقلها لأي حاسوب آخر أو الاحتفاظ بها بأمان.
   - **زر استيراد نسخة احتياطية (JSON)**: لاستعادة أو مزامنة التعديلات بنقرة زر.
   - **زر استعادة البيانات الأصلية**: للعودة للنسخة الأولية المعتمدة في أي وقت.

4. **تصدير وطباعة السيرة الذاتية (Print CV / PDF)**:
   - تنسيق طباعة أكاديمي منسق تلقائياً يخفي أزرار التحرير ويوثق السيرة الكاملة بمظهر رسمي للجامعات والمراكز البحثية.

5. **محرك بحث داخلي سريع**:
   - إمكانية البحث الفوري في عناوين الكتب، الدوريات، سنوات النشر، وملخصات الأبحاث.

## 🚀 كيفية تشغيل المنصة

المنصة مصممة بتناغم عالي كصفحة ويب مستقلة ذاتية التشغيل لا تحتاج إلى أي تثبيت مسبق:

1. افتح المجلد:
   `C:\Users\user\.gemini\antigravity\scratch\anees-platform`
2. اضغط مرتين على ملف **`index.html`** ليفتح فوراً في أي متصفح (Google Chrome, Microsoft Edge, Firefox, Safari).
3. للبدء في التعديل والإضافة، اضغط على زر **"تفعيل وضع التحرير"** في الشريط العلوي.

---

## 🌐 خيارات نشر المنصة على الإنترنت مجاناً

يمكنك نشر المنصة ليتصفحها القراء والباحثون في جميع أنحاء العالم مجاناً من خلال إحدى الطرق التالية:

### الخيار 1: عبر Netlify Drop (الأسهل في دقيقة واحدة وبدون أي كود)
1. افتح موقع [app.netlify.com/drop](https://app.netlify.com/drop).
2. اسحب مجلد `anees-platform` وأفلته في الصفحة.
3. ستحصل فوراً على رابط عالمي مجاني وسريع (مثل: `anees-eladel.netlify.app`).

### الخيار 2: عبر Vercel
1. سجّل دخول في [vercel.com](https://vercel.com).
2. ارفع مجلد المشروع أو اربطه بمستودع GitHub لتحصل على استضافة عالمية مجانية مع شهادة أمان SSL.

### الخيار 3: عبر GitHub Pages
1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub باسم `anees`.
2. ارفع ملف `index.html`.
3. من إعدادات المستودع (Settings -> Pages)، فعّل خيار النشر من فرع `main`.
